Offline unlocker

Opens a .tzlock file. Works with no internet connection — nothing on this page is loaded from anywhere, and nothing you put into it leaves your device.

    What this page is, and why it exists

    A file in a format only one website can read is a file that depends on that website existing. This page removes that dependency: it is one self-contained HTML file with no scripts, stylesheets or fonts loaded from anywhere, so it keeps working from a USB stick, offline, indefinitely. Save a copy alongside anything important you lock.

    It is also the specification. The comment at the top of this file’s source describes the format completely — open it in a text editor — and the code below it is a working reader in about two hundred lines. Anyone can write another one.

    The encryption is AES-256-GCM with the key derived from your password by PBKDF2-HMAC-SHA256, using the browser’s own cryptography. The whole header is authenticated along with the contents, so a file that has been altered refuses to open rather than opening wrongly. There is no recovery if the password is lost — that is the point of it.
